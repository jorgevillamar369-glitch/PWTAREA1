¿Quiénes somos?

Somos un grupo de cinco estudiantes de la Universidad Bolivariana del Ecuador que desarrollamos esta actividad para aplicar nuestros conocimientos de HTML y CSS.

Mediante este proyecto practicamos la creación de páginas web, la organización de contenidos, el diseño visual y la navegación.

Objetivos del Proyecto

Nuestro objetivo es desarrollar habilidades en programación web mediante la aplicación de HTML y CSS.

Buscamos comprender la estructura de una página web, aplicar estilos, crear menús de navegación y desarrollar diseños responsivos.
